## 已执行

- `uv sync --locked --extra dev`：可从锁文件同步依赖，项目入口可运行。
- `OPENBLAS_NUM_THREADS=1 uv run --locked --extra dev pytest -q`：13 passed。
- `uv run python examples/01_minimal_loop.py`：无图形完整闭环，外力时预测误差可见。
- `mpc-demo run --scenario demo`：10 秒仿真，完整逐拍日志。
- `mpc-demo compare --kind controllers --scenario push`：MPC、同一全时长窗口 MPC/开环、PD。
- `compare --kind horizon`：reach、brake 两个场景。
- `compare --kind mass --scenario push`：重车、模型错误、匹配模型。
- `compare --kind preview --scenario switch`：当前目标与未来目标预瞄。
- 原生 MuJoCo GLFW viewer：短时自动结束冒烟验证；`run_demo.sh` 也已执行。
- EGL 离屏渲染：导出 960×540、20 FPS、10 秒 H.264 MP4，并提取帧检查。
- 所有生成日志：时间、状态、动作、预测轨迹维度一致。
- HTML：检查内嵌 JSON 与 JavaScript 语法。内置浏览器拒绝 file:// URL，本次未做浏览器交互验收；没有改走其他浏览器路径。可以由用户在普通浏览器打开本地报告。

## 测量结果的范围

默认 push 场景中，MPC 末端误差小于 0.001 m；同一全时长窗口开环末端误差约为 3.922 m。示例 PD 峰值速度约为 2.311 m/s，MPC 约为 1.300 m/s。每次运行的精确统计以对应输出目录的 metrics.json 为准。

这些是单机、指定参数与场景下的结果，不是算法稳定性或硬实时保证。规划耗时包括 Python 更新与 OSQP 求解，不含仿真、渲染和调度。比较反馈与开环时，两者用相同全时长窗口；默认 N=40 的 MPC 另作一组，避免将预测窗口的影响混到反馈对照中。
